TCGplayer has no public API for sealed product pricing and blocks automated requests to its site, so this can't be pulled automatically. Instead, add the products you want to track in the SealedProducts tab of your data sheet, fill in the current TCGplayer market price yourself (and pick an Era from the dropdown in that column), then hit Refresh Now — each refresh snapshots whatever's in that sheet so trends build up over time.
